# 見ていたこと

誰かについて覚えている三つの小さなことを、その人へ渡す短い作品。

- 送る人が、ある人について覚えている些細な具体を三つだけ書きます（メッセージ欄はありません）
- できたリンクを、その人にだけ送ります
- 受け取った人は、簡素な空間を奥へ進みながら、三つを一つずつ受け取ります
- 返事の仕組みも、既読も、開封通知もありません

## 仕組みと約束
- 1ファイルのHTMLです。サーバーはありません。書いた言葉はリンクの `#` 以降にだけ入っていて、AIにも制作者にも送られません
- この作品の箱（画面・順番・間・文章）は、制作者がAIと作りました。中に入っている言葉は、送った人のものです
- 嫌がらせ・つきまとい・連絡を拒否された相手への送付・繰り返しの送付には使えません

## ファイル
- `index.html` — 作品本体（これ1つで動きます）
